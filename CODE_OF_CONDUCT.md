# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## In short

- Be respectful and welcoming, whatever someone's background or experience.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its community.
- Harassment, insults, personal or political attacks, and publishing others' private information are not acceptable.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when someone represents the project in public.

## Enforcement

Report unacceptable behavior privately to the maintainer, [laurentvandelle](https://github.com/laurentvandelle), through GitHub. All reports are reviewed promptly and kept confidential. The maintainer may edit or remove contributions, or temporarily or permanently ban anyone who breaks this code, following the enforcement guidelines of the Contributor Covenant.
